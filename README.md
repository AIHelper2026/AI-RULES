# AI-RULES

Shared engineering rules profile for AI coding assistants.

Single-file repository: `RULES.md` is the canonical assistant standard
used across our projects. Point your assistant (OpenCode, Cursor, Claude
Code, etc.) at this file, or copy its content into your project's
instructions file.

Update cadence: weekly. The freshest version always supersedes cached
copies.

Feedback: open an issue or reach the maintainers internally.
